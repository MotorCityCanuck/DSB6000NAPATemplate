# Test Guide

The `tests/` directory is reserved for implementation tests and student-developed analytical tests. The current template intentionally contains no executable tests; teams create tests as implementation progresses.

## Testing responsibilities

- Bronze tests must verify the contracts defined by `docs/raw_to_bronze_prompt.md`.
- Silver tests must verify the contracts defined by `docs/bronze_to_silver_prompt.md`.
- Test coverage should address the five approved dataset profiles as required by the construction prompts.
- Students should develop additional Gold tests for their own analytical designs, features, metrics, and recommendations.
- No particular Gold scoring, ranking, modeling, or selection method is prescribed.

## Working expectation

Add tests only after the corresponding project logic exists and the team can explain the expected behavior. Keep test evidence aligned with the team's methodology, data quality, lineage, and reproducibility documentation without duplicating the detailed construction-prompt test matrices here.
